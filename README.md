# Sensor_Fusion
Sensor fusion using EKF for Wheel Odometry, LiDAR, DGPS+INS, UWB Tags for University project Autonomous Rover Navigation. 

**1.1)** A real-time sensor fusion system for an autonomous rover, fusing LiDAR and Wheel Odometry data using an Extended Kalman Filter (EKF) to achieve accurate positioning.

## 🚀 Features

- **Extended Kalman Filter (EKF)** implementation for sensor fusion
- **Multi-sensor support**: LiDAR (2Hz) + Wheel Odometry (5Hz)
